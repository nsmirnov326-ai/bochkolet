# БОЧКОЛЁТ

Рофельный 2D-симулятор. Открыл страницу — уже играешь.

Прогресс, рекорд и выбранный самолёт лежат в `localStorage` этого браузера. Сервер только отдаёт страницу и файлы, общего мира нет: сколько людей зашло параллельно, столько независимых рейсов.

## Управление

- W / S или стрелки — высота
- A / D — полоса
- Пробел — речь

## Деплой на RelaxDev

Репозиторий: `nsmirnov326-ai/bochkolet`.

1. На [relaxdev.ru](https://relaxdev.ru) добавь проект из GitHub, ветка `main`.
2. Тип сборки: **Docker** (в репозитории есть `Dockerfile`). Если оставить автоопределение, команда запуска всё равно `npm start`: сервер слушает `0.0.0.0` и порт из `PORT` (платформа ставит 8080).
3. Секреты и база не нужны. `DATABASE_URL` не задавать.
4. После деплоя игра открывается по адресу проекта. Каждый посетитель играет у себя, чужой прогресс не затирается.

Локально прод-сборка: `npm run build && npm start`.
